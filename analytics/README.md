# Titanic Data Analysis and Machine Learning Project

## Project Overview

This project uses the Titanic dataset to perform **Exploratory Data Analysis (EDA)** and **Machine Learning modeling** using Python.

The project is divided into two Python files:

1. `01eda.py` - Exploratory Data Analysis
2. `02modeling.py` - Machine Learning Modeling

The output from the EDA stage is used as the input for the modeling stage.

---

## Project Structure

```text
project/
│
├── 01eda.py
├── 02modeling.py
├── titanic.csv
├── charts/
└── README.md
```

---

# 1. 01eda.py

The first Python file performs Exploratory Data Analysis on the Titanic dataset.

### Main activities

- Loads the Titanic dataset using Seaborn.
- Saves the dataset as `titanic.csv` for later use.
- Displays basic information about the dataset.
- Checks the dataset shape and descriptive statistics.
- Identifies missing values.
- Calculates missing-value counts and percentages.
- Performs data cleaning and preparation.
- Analyzes survival based on different passenger characteristics.
- Creates visualizations using Matplotlib and Seaborn.
- Saves charts for further reference.

The main purpose of this file is to understand the dataset before building machine learning models.

---

# 2. 02modeling.py

The second Python file performs machine learning modeling using the cleaned Titanic dataset.

It reads the `titanic.csv` file created by the EDA stage.

### Main activities

- Loads the Titanic CSV file.
- Selects the target variable:
  - `survived`
- Selects relevant features such as:
  - `pclass`
  - `sex`
  - `age`
  - `sibsp`
  - `parch`
  - `fare`
  - `embarked`
- Splits the data into training and testing datasets.
- Handles numerical and categorical features.
- Performs missing-value handling.
- Uses scaling and one-hot encoding where required.
- Builds machine learning pipelines.
- Applies classification models such as:
  - Logistic Regression
  - Decision Tree
  - Random Forest
- Uses SMOTE where required for handling class imbalance.
- Evaluates models using classification metrics.
- Performs model comparison and tuning.
- Includes regression-related modeling and evaluation.
- Saves trained models using `joblib`.

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn joblib
```

---

# How to Run

## Step 1 - Run EDA

```bash
python 01_eda.py
```

This performs the exploratory analysis and creates the Titanic CSV file used by the next stage.

## Step 2 - Run Modeling

After `01_eda.py` has completed successfully:

```bash
python 02_modeling.py
```

The modeling script reads `titanic.csv` and performs the machine learning workflow.
